# Run a diagnosis drill

Have the instructor choose either gateway-down or source-down without telling you which one. Start from the user-visible symptom and record each diagnostic step before running it.

After restoring service, explain:

1. Which observation isolated the failure?
2. Which tempting change would have been unnecessary or destructive?
3. What did the automated validator prove?
4. What additional application test was required?
5. How would the impact differ during full load versus after cutover?

Repeat the drill until you can repair it without opening the recovery section. Measure diagnosis and repair time separately.
